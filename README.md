# はぁって言うゲーム (Haa Game Online)

「はぁ」や「なんで」といった短い言葉を、与えられたシチュエーションに合わせて演技し、何を演じているかを当てるパーティゲームのWebアプリ版です。
オンラインマルチプレイに対応しており、離れた場所にいる友達と一緒に遊ぶことができます。

## 特長

- **オンラインマルチプレイ**: Firebase Realtime Databaseを使用したリアルタイム同期。
- **ルーム制**: ルームIDを共有するだけで簡単に合流。
- **個別お題モード**: 全員が異なるお題（「はぁ」「えー」など）でプレイ可能。
- **モバイル対応**: スマートフォンでの操作に最適化。

## 遊び方

1. **ロビー**: 名前を入力し、ルームを作成するか、友達から共有されたルームIDを入力して参加します。
2. **待機室**: 全員が揃ったらホストがゲームを開始します。
3. **お題確認**: 自分の番になったら、自分だけにお題が表示されます。他の人は演技の選択肢を確認して待機します。
4. **演技**: お題のシチュエーションに合わせて演技をします。
5. **投票**: 演技者以外の全員が、どのシチュエーションだったかを予想して投票します。
6. **結果**: 全員の演技が終わると、スコアが表示されます。

## 技術スタック

- React
- TypeScript
- Vite
- Tailwind CSS
- Firebase Realtime Database

## 開発と実行

### セットアップ

```bash
npm install
```

### Firebaseの設定

1. Firebaseコンソールでプロジェクトを作成し、Realtime Databaseを有効にします。
2. `src/logic/firebase.ts` 内の `firebaseConfig` を自分のプロジェクトの設定に書き換えます。

### 開発用サーバーの起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```
